# Comu

A bite-sized ch32 board that goes directly into your USB port.

![](images/3d.png)

Features:
- 4x touch buttons
- 2x LEDs
- 1x ch32v203
    - USB HS
    - 64k Flash, 20k sram
- 6x GPIO broken out via testpads
- On-PCB USB-A connector

![](images/comu.png)

By pluggin in this PCB, you will have a portable bare-metal USB HID device that you can play with :)
